# Software Wallah — Website

A responsive education website built with plain HTML, CSS and JavaScript.

## Run it on Windows 11 with VS Code
1. Extract `software-wallah.zip` to a folder.
2. Open Visual Studio Code.
3. Choose **File → Open Folder** and select the extracted `software-wallah` folder.
4. Open `index.html`.
5. Easiest option: double-click `index.html` in File Explorer to open it in your browser.
6. Recommended live preview: in VS Code, open **Extensions** (`Ctrl+Shift+X`), search for **Live Server** by Ritwick Dey, install it, then right-click `index.html` and choose **Open with Live Server**.

No Node.js, build tools, paid plan or account is required.

## Included features
- Responsive layout for desktop, tablet and mobile
- Light/dark mode (remembers your choice in this browser)
- Course search, category filter and level filter
- Course overview dialog cards
- Mobile navigation menu
- Scroll reveal animations and hover effects
- Accessible labels and reduced-motion support

## Edit the site
- `index.html`: text, course cards and page sections
- `style.css`: colors, layout, spacing and responsive design
- `script.js`: search/filter logic, dark mode, menu and course dialogs

Note: this is a front-end demo. Login, user accounts, enrolment, and contact submission are not connected to a backend.
